# مركز غيم لضيافة الأطفال — النظام الكامل

## ما يعمل الآن
- لوحة رئيسية وإحصائيات.
- إضافة الطلاب ومستويات: تمهيدي / KG1 / KG2.
- ملف مالي مستقل لكل طالب.
- تسجيل دفعات متعددة لكل طالب.
- طرق الدفع: بنكي، شبكة، قرة، تابي.
- منع تسجيل دفعة أكبر من المتبقي.
- سجل مدفوعات مع فلترة بالطالب والمستوى وطريقة الدفع والتاريخ.
- جدول مواعيد قادمة مع أيام الدوام الأحد–الخميس.
- تقارير إجمالية وحسب المستوى وحسب طريقة الدفع.
- طباعة جدول المواعيد والتقارير.
- PWA للتثبيت على سطح المكتب عند تشغيله من HTTPS/GitHub Pages.
- ملف Google Apps Script مبدئي للربط مع Google Sheets.

## مهم
الواجهة الحالية تعمل محليًا باستخدام LocalStorage حتى تفتح المشروع فورًا وتختبره.
للتشغيل الجماعي عبر أجهزة متعددة، ضع معرف Google Sheet في `gas/Code.gs` وانشر Apps Script كـ Web App، ثم اربط `api.js` بالواجهة. لم يتم فرض API غير موجود أو وضع رابط وهمي.

## GitHub Pages
ارفع الملفات كما هي إلى المستودع، ثم فعّل GitHub Pages.

## الحماية
- صفحة دخول بكود.
- الكود الافتراضي لأول تشغيل: 1234.
- يمكن تغيير الكود من الإعدادات.
- يوجد زر تسجيل خروج.

## الربط مع Google Sheets
تم ضبط `js/api.js` على رابط Google Apps Script Web App الخاص بمركز غيم. عند فتح النظام يتم جلب البيانات من Google Sheets، وعمليات إضافة/تعديل/حذف الطلاب والمستويات وطرق الدفع وتسجيل المدفوعات ترسل إلى الـ API.

> بعد تحديث `gas/Code.gs` في Apps Script، يجب إعادة نشر Web App كنسخة جديدة/تحديث الـ deployment.

## تحديثات الإصدار
- إضافة رقم ولي الأمر في بيانات الطالب.
- البحث يمكنه استخدام رقم ولي الأمر.
- إظهار رقم ولي الأمر في كشف الطالب.
- أزرار العمليات تمنع الضغط المكرر وتعرض حالة جاري التنفيذ.
